Кто издатель

Издатель — физическое лицо-предприниматель (ФОП), зарегистрированное в Украине. Юридическое имя указано на странице продукта в Microsoft Store. Вопросы: GitHub Issues или адрес поддержки в карточке Store.

Что делает приложение

Программа на этом компьютере читает состояние батареи через Windows API (IOCTL драйвера батарей и GetSystemPowerStatus) и показывает мощность в области уведомлений. Она не создаёт учётную запись и не ходит в интернет за данными батареи.

Какие данные

  • Показания батареи обрабатываются только на устройстве и никуда не отправляются.
  • Язык, тема окна и автозапуск хранятся локально в реестре текущего пользователя Windows.
  • Телеметрии, аналитики, рекламных идентификаторов и своей аналитики нет.
  • Платежи за будущее дополнение Pro принимает Microsoft Store. Номер карты и платёжный профиль издатель не получает.

Этот сайт

Сайт статический, на GitHub Pages. Своих cookie нет; выбранный язык страницы может сохраниться в localStorage браузера. GitHub как хостинг может вести технические журналы (IP, User-Agent) по своим правилам.

Дети

Приложение не предназначено для сбора данных детей и не запрашивает возраст.

Privacy policy

Effective 24 November 2026. Covers the Battery Power Indicator app and this website.

Publisher

The publisher is a sole proprietor (FOP) registered in Ukraine. The legal name is the one shown on the Microsoft Store product page. Contact: GitHub Issues or the support email on the Store listing.

What the app does

On this PC the app reads battery status through Windows APIs (the battery-class driver IOCTL and GetSystemPowerStatus) and shows power in the notification area. It does not create an account and does not send battery data to a network service.

Data

  • Battery readings stay on the device. They are not uploaded.
  • Language, window theme, and start-at-sign-in are stored locally in the current-user Windows registry.
  • There is no telemetry, analytics, advertising identifier, or first-party analytics.
  • Payment for a future Pro add-on is handled by Microsoft Store. The publisher does not receive card numbers or your Microsoft payment profile.

This website

The site is static hosting on GitHub Pages. It does not set its own cookies; the language choice may be stored in the browser’s localStorage. GitHub may keep technical logs (IP address, User-Agent) under GitHub’s own terms.

Children

The app is not designed to collect children’s data and does not ask for age.
